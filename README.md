## Proyectos

**[SmartDesk](https://github.com/GaryMp/smartdesk)**

Recibe solicitudes de soporte, las guarda en PostgreSQL y las clasifica con
Gemini a través de n8n. NestJS, Prisma, Docker y pruebas automatizadas.

**[FreeRadio](https://github.com/GaryMp/freeradio)**

Complemento para NVDA que permite escuchar radio en línea con el teclado.
Tiene su propio sitio con descargas, reseñas y emisoras que aporta la
comunidad, sobre Cloudflare Pages y D1.

[freeradio.digitalaccessibility.cl](https://freeradio.digitalaccessibility.cl)

**[ClimaSpeak](https://github.com/GaryMp/clima_speak)**

Complemento para NVDA que te dice el clima con un atajo de teclado.
